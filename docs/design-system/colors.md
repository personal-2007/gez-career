# Design System: Colors

## Core palette

- Primary Blue: #2563EB
- Bright Blue: #3B82F6
- Premium Purple: #7C3AED
- Soft Purple: #A855F7
- Deep Navy: #0F172A
- Background: #F8FAFC

## Semantic tokens

- Primary: `--primary`
- Primary Hover: `--primary-hover`
- Success: `--success`
- Warning: `--warning`
- Danger: `--danger`
- Text: `--text-main`
- Muted text: `--text-muted`
- Inverse text: `--text-inverse`

## Usage guidance

- Use primary blue for primary actions and CTA emphasis.
- Use deep navy for high-contrast text and dark surfaces.
- Use purple accents for premium or AI features.
- Keep backgrounds light and surfaces airy to maintain readability.

## Flutter mapping

React token examples map to Flutter colors like this:

- `--primary` -> `Color(0xFF2563EB)`
- `--deep-navy` -> `Color(0xFF0F172A)`
- `--bg-page` -> `Color(0xFFF8FAFC)`
