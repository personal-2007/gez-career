# Design System: Typography

## Font scale

- Display: 40px / 48px / 700
- H1: 32px / 40px / 700
- H2: 24px / 32px / 600
- H3: 20px / 28px / 600
- Body: 16px / 24px / 400
- Small: 14px / 20px / 400
- Caption: 12px / 16px / 500

## Usage

- Use a strong sans-serif for headings.
- Use clear body type for long-form content and UI labels.
- Maintain generous line-height for accessibility.

## Flutter mapping

- React heading styles -> `TextStyle(fontSize: 28, fontWeight: FontWeight.w700, color: Color(...))`
- React body text -> `TextStyle(fontSize: 16, fontWeight: FontWeight.w400)`
