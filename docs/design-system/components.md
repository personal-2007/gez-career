# Design System: Components

## Button styles

- Primary button: gradient blue fill, strong shadow, 48px minimum touch height
- Secondary button: neutral surface with border
- Ghost button: transparent background with text emphasis

## Input styles

- Rounded medium corners
- 48px height minimum
- Clear focus ring and label contrast

## Cards

- White or light neutral background
- Subtle border and shadow
- 12px to 20px internal spacing

## Dialog patterns

- Simple confirmation dialogs
- Full-screen bottom sheets on mobile
- Desktop modal with max width and centered layout

## Flutter mapping

- `Button` -> `ElevatedButton` / `TextButton`
- `Input` -> `TextFormField`
- `Modal` -> `Dialog` / `showModalBottomSheet`
