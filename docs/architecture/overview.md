# GEZ Career Architecture Overview

GEZ Career is built using a clean 3-tier architecture:

```
[ React 18 SPA Client ]  <--->  [ Express 4 REST API Gateway ]  <--->  [ AI Engine & Datastore ]
    (Vite / Lucide)                  (JWT / Middleware)               (Agents / MemoryDB / Vector Embeddings)
```
